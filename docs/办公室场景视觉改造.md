# 办公室场景视觉改造

## 目标

参考用户提供的明亮日系街景图片，将办公室做成有日光、空间层次和生活细节的场景。保持现有八个区域、门洞、掩体和导航边界，避免美术调整改变战斗路线。

当前第一版已调整日光、浅色墙地面、桌椅结构、窗框、顶灯和绿植。它用于确认整体方向；达到参考图的丰富度还需要制作更完整的场景模块。

## 场景搭建方式

用一套可重复组合的办公室模块搭建各房间，不为每个房间分别制作一套完整模型。先统一墙面、地面和家具之间的相对比例，再用配色、摆放密度、灯光及少量标志物区分工位区、会议室、老板办公室、补给区、档案区和休息区。

| 优先级 | 可复用模块 | 用法 |
|---|---|---|
| 1 | 浅色地砖、地毯、木饰面、乳白墙面 | 统一低噪点材质，靠色彩和宽度区分区域 |
| 1 | 直墙、转角、门洞、窗框、踢脚线 | 拼出已有房间和通道，不改碰撞边界 |
| 1 | 工位桌、办公椅、显示器、顶灯 | 形成一眼能认出的办公室主体 |
| 2 | 会议桌、白板、书柜、文件柜、茶水台 | 给不同区域建立用途和轮廓 |
| 2 | 盆栽的 2～3 种叶形、纸张、杯子、公告板 | 增加生活感，避免大面积重复 |
| 3 | 窗外城市景片、装饰画、百叶帘、细小桌面物 | 在主视觉通过后补充近景细节 |

建议先制作约 12～18 个可复用的 3D 模块和 4～6 张可平铺表面贴图，再组合出不同办公室。桌椅、植物和窗框使用变体配色与摆放，减少重复感。贴图优先保证大色块、柔和接缝和清晰材质，不叠加随机像素噪点。

## 光照与移动端

- 主光源设为偏暖日光，天光偏冷；墙面和地板以浅米色、浅灰绿、浅蓝灰为主，木质家具提供暖色焦点。
- 窗户附近用局部亮斑表现光照方向；顶灯负责辨认办公室功能，不用大量真实点光源堆亮度。
- 保持玩家、敌人、弹道和可拾取物与环境之间的明度及色相差，优先保证手机竖屏上的战斗辨识度。
- 重复物件尽量复用几何体和材质；后续 GLB 资产沿用项目的纹理压缩与 Meshopt 流程，实机检查 draw call、帧率和加载体积。

## 下一步验收

1. 手机竖屏完整跑一局，核对新亮度下敌人、准星、弹道、掉落物和门洞是否清晰。
2. 确认这版的配色和日光方向后，将主要家具与窗墙模块替换为正式低面数模型。
3. 在同一镜头下对比工位区、会议室、茶水区与档案区，让每个房间有明显但统一的用途特征。
